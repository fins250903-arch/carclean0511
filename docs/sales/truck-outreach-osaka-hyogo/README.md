## ファイル

- `leads.csv` / `leads.json` — 送信先リスト（100件）
- `generate_leads.py` — リスト生成元

`wave` 列:

| wave | 意味 |
| --- | --- |
| 1 | 規模が近く、メール・Instagram・フォームがある。最初に送る |

`best_channel` は推奨の最初の接点です。`営業電話お断り` とある会社はメール/フォーム/DMのみにしてください。

## 収集方法

地域を分割して並行調査しました。

1. 大阪府トラック協会・西支部 会員名簿（社名・住所・TEL/FAX）
2. 大正支部リンク、重量部会
3. 兵庫県トラック協会 ダンプ部会名簿、引越部会名簿（メール掲載あり）
4. 各社公式サイトの会社概要・お問い合わせ
5. ハローワーク求人の従業員数、ドラEVER の車両台数
6. Instagram / X の公式アカウント

メールアドレスは公式サイトまたは協会PDFに載っているものだけです。推測で作っていません。

## 送り方の注意

- 特定電子メール法の対象になり得ます。送信者名・連絡先・配信停止方法を必ず書いてください。
- 「営業電話お断り」は電話しない。
- 協会名簿の電話は業務連絡用です。長時間の売り込みは避け、1通（1回）＋お断り時は停止。
- Instagram はビジネスアカウントへの短いDMに留め、連投しない。
- 個人のプライベートアカウントには送らない。
- リストは公開情報のスナップショットです。送る直前にサイト・番号を再確認してください。

## 案内文のたたき台

件名例: `トラックキャビン清掃のご案内（大阪・兵庫 / 車内清掃特急便）`

本文の骨子:

- 名乗り: 岡山の車内清掃「特急便」、今村
- 何をするか: 営業車・トラックキャビンのシート・におい・汚れの出張清掃
- なぜ今: ドライバー確保・車両の印象・交代制の衛生
- 規模感: 1台から、車庫や営業所での出張
- 次の一歩: 写真3枚をLINE/メール、または空き日の確認
- 配信停止: 「不要」と返信ください
- 連絡先: 070-8428-0866 / Instagram @carinterierclean / https://carinteriorcleaning.jp/regions/osaka/

Instagram DM は3〜4行で。長文は送らない。
