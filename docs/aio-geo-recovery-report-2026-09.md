# AIO / GEO 上位奪還レポート（2026-09）

対象: https://carinteriorcleaning.jp/  
サービス: 出張型車内クリーニング清掃（特急便）

## 1. 各サブエージェントからの報告サマリー

### 分析エージェント（LP Analyst）の見解
- **強み**: Answer-First / Speakable / FAQPage / HowTo、嘔吐4日ルール、灯油重症度マトリクス、保険判断表、状況診断表、365日24時間・最短即日の明記、地域LP網が厚い。
- **課題**: (1) KW LPでFV画像が意図と不一致（灯油→スチーム、おもらし→汎用シミ等）。(2) 競合が「最短2時間／受付○分」と具体化する一方、自社は「最短即日」止まりで到着目安が弱い。(3) 地域診断表が嘔吐・灯油偏重で、おもらし／タバコ／おすすめ選択のInformation Gainが薄い。(4) スマホFV写真帯が低く、内容と背景画像の一致が伝わりにくい。

### Web検索エージェント（Search Trend Researcher）の見解
- AIOが発動しやすいのは情報型＋緊急型の合成クエリ: `車 嘔吐 クリーニング`、`車内 灯油 消し方`、`近くの車内掃除業者`、`車のシートのシミの落とし方`、音声系「運転中に吐いた」「今すぐ来て」。
- 引用されやすい形式: 数値（4日／100cc／料金帯）、手順（やってはいけないこと）、比較表、状況→メニュー対応。
- DIY・コラムサイトが灯油クエリを奪いやすい → **量別マトリクス＋保険＋即日出張**の三点セットが勝ち筋。

### 競合調査エージェント（Competitor Intel）の見解
- AUTO CLEANING 等は「最短2時間」「受付最短5分」「代車」「スポーツ保険」で緊急CTRを取る。
- ディーラー／カー用品店は交換・商品販売中心で緊急抽出洗浄の深さは弱い。
- **自社の独自Information Gain**: 嘔吐4日ルール、灯油量別重症度、保険代理申請＋実質自己負担併記、発電機＋水タンク（地下駐車場）、写真3枚LINE診断、成功率の正直開示（タバコ70–80%）。

## 2. AIO表示頻度低下の要因分析（仮説）
1. **緊急クエリの具体性競争**: 競合が時間単位の約束語を前面化し、AI要約が「即応」の根拠として競合を優先した可能性。
2. **FV／意図ミスマッチ**: 広告・KW流入で画像と訴求がずれ、エンゲージメント低下→再クロール評価の相対低下。
3. **お悩み解決型の網羅不足**: おもらし・たばこ・おすすめ比較の話し言葉見出しが相対的に薄く、ロングテール音声クエリの引用枠を逃した。
4. **DIYコラムの情報型独占**: 灯油・シミの消し方クエリで汎用コラムがAI Overviewの主引用になり、出張専門の差別化ブロックが埋もれた。

## 3. 実装した具体策（本ラウンド）
- KW FV整合（実画像レビュー込み）:
  - `omorashi.png` / `touyu-kobosi.webp` はファイル名と異なり同一の駐車場ストックだったため不採用。
  - おもらし／おしっこ → `seat-stain-dark.webp`（尿染み視覚）
  - 灯油 → `rinser-work.jpg`（抽出洗浄の専門工程）
  - 臭い・加齢臭・エアコンも意図一致画像へ差し替え。
- Hero: 「最短即日・緊急対応」バッジ、フッター「最短即日対応」、スマホ写真帯の視認性向上。
- 状況診断表の拡張（おもらし／タバコ／ペット／シミ／おすすめ）。
- 音声ライン・Answer-Firstに到着目安（数時間以内枠）と話し言葉キーワードを追加。
- FAQ追加: おすすめ比較／たばこヤニ／最短到着・受付。
- QuickFacts: 「最短即日空き確認／作業1.5〜3時間」。
