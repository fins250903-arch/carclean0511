今回は　猛暑　いや　酷暑が続きます\
その暑い季節の中　体調も崩しやすい人が多いです\
\
今回のお客様も後部座席に乗っていた友人が体調を崩して急に嘔吐されたそうです\
\
気温の時期もあって　独特な匂いが立ち込める　ということで\
早急に対応いたしました　　一次対応の処理を　されていて　お客さまご自身ではなんとか　対応をしようということでやってみた　が　やはり匂いが　なかなか取れない　\
　シートの縫い合わせの隙間あたりに染み込んでいるようで　そういったのが取れないと\
　匂いが　ぶり返す　それと殺菌を　しっかりお願いしたいと　ご依頼頂きました

シートの汚れてる箇所にしっかりと洗剤を染み込ませ　ブラッシングで汚れを出していきます　　これを繰り返すことを何回か行います　　　\
\
その上からスチームをかけてさらに奥に走り込んだ　汚れを浮き出させます　　座席もファブリックが中心だったので洗浄機をかけて、洗剤と水を吸い上げて綺麗に仕上げを行いました　　　

　嘔吐物に　含まれる病原性のものが含まれてる可能性もないとは言えません\
そこで殺菌消臭の効果の高いオゾン消臭機を投入し　追加の施工をいたしました\
\
完了まで約2時間ほどかかりました　\
費用合計は　嘔吐の範囲が広かったので　今回は3万2000円ほどとなりました\
\
シートの汚れもなくなり　元の状態まで復活し　匂いも除去できたと大変お喜びをいただきました

\
汚物が残ったまま放置されると　匂いがさらに染み込んでいく　今回のお客様も初期対応が的確で染み込みも少なかったことが匂い状況ができた一番の大きな要因だと思います
