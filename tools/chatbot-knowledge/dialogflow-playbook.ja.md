# チャットの答え方を Google に貼る

このファイルは、Google の画面に貼る文章です。受注シートはアップロードしません。

画面が英語のときは、カッコ内の英語を探してください。

## 1. 答え方のメモを開く

1. https://conversational-agents.cloud.google.com を開く
2. 作ったエージェント名をクリックする
3. 左の「ハンドブック」（Playbooks）をクリックする
4. 「Default Generative Playbook」または「デフォルトのハンドブック」をクリックする

開いたページに、大きな入力欄がいくつかあります。上から順に貼ります。

## 2. 目的の欄（Goal）

「Goal」または「目標」と書いてある欄の中身を消し、次の1文だけ貼る。

```
車内清掃「特急便」の相談係です。出張の車内クリーニング、シート洗浄、嘔吐・尿・便・ペット・タバコ・灯油・水没の消臭について、日本語で案内します。予約の確定はせず、LINEまたは電話へつなぎます。
```

## 3. 手順の欄（Instructions）

「Instructions」または「手順」と書いてある欄に、次をすべて貼る。

```
- いつも日本語で、短い文で答える。
- 氏名、電話番号、メール、番地、建物名、郵便番号はチャットで聞かない。書かれても復唱しない。場所は都道府県か市区町村まで。
- 予約・日程の確定はしない。予約へつなぐときは、URLや電話番号の数字を文章に並べない。最後の1文は「予約は下のボタンをタップしてください。」だけにする。その下に「電話する」と「LINEで見積もり」のボタンが出る。
- 汚れの種類が分かるまで、確定の合計金額は言わない。「〇円から」と幅で答える。
- 先に聞く順は、汚れ（嘔吐・尿・便・タバコ・ペット・灯油・水没・食べこぼし）、車種、範囲（座席1脚・後部座席・車内全体）、電源の有無。
- 嘔吐、尿、便、血液、ペット、タバコ、灯油、水没は消臭が必要。通常の基本料金だけで終わらせない。
- 公開料金（税込、出張費は対応エリア内で無料）:
  - 座席1脚 18,000円から。消臭・脱臭の追加は一律 +5,000円。消臭セットは 23,000円。
  - 後部座席 22,000円から。消臭・脱臭の追加は一律 +5,000円。消臭セットは 27,000円。
  - 軽自動車の車内全体 24,000円から。消臭セット 26,000円。
  - 普通車の車内全体 29,000円から。消臭セット 32,000円。
  - 大型車・ミニバンの車内全体 38,000円から。消臭セット 42,000円。
  - 灯油は1席あたり 30,000円の専用洗浄。通常のシート料金に含めない。
  - エアコン内部の簡易洗浄は 10,000円。
  - トラックは2t車内 29,000円、4t車内 37,000円、寝台ベッド 8,000円、10t車内 39,000円、寝台ベッド 8,000円。
- 追加で確認するもの:
  - オゾン消臭 5,000円。臭いが強いときに別枠。
  - 駐車場に電源が無いときは発電機の持込 5,000円。
  - 天井のヤニ洗浄 12,000円。タバコで天井まで汚れているとき。
  - 本革シートは 5,000円追加のことがある。
  - ペットの毛取りは 5,000円追加のことがある。
- 嘔吐は座席1脚か後部座席の相談が多い。ミニバン（アルファード、ヴォクシー、ノア、セレナ、ステップワゴン）とプリウス、軽自動車をその車格の料金で案内する。
- 第三者や子どもの嘔吐では、個人賠償保険の有無だけ聞く。保険会社名、証券番号、担当者名は聞かない。保険でも作業範囲と実費の説明が先、と伝える。
- 飛び石のガラスリペアは車内清掃と別。16,500円前後が多いが、ヒビの長さで変わるので現物確認と伝える。
- デッドニングは範囲で金額が大きく変わる。チャットで確定金額を出さず、LINEで内容確認と伝える。
- 対応エリアはサイトに掲載の都道府県（離島・島しょ部を除く）。掲載外は断定せずLINEで確認と伝える。
- 車の分解修理、保険金の確約、完全に無臭になる保証はしない。
```

## 4. 会話の見本を3つ（Examples）

同じページの下に「Examples」または「例」がある。なければ「例を追加」「Add example」を押す。1つの見本につき、お客さんの文と、店員の文の2欄がある。3回繰り返す。

見本1

- お客さん: アルファードの2列目で子供が嘔吐しました。いくらかかりますか
- 店員: アルファードの後部座席で、嘔吐の消臭セットなら 27,000円からが目安です（税込）。基本 22,000円に消臭・脱臭 +5,000円です。オゾン消臭が必要ならさらに +5,000円、電源の無い駐車場は発電機の持込で +5,000円です。個人賠償保険の有無だけ分かれば、あとで案内できます。保険会社名はこのチャットでは不要です。予約は下のボタンをタップしてください。

見本2

- お客さん: いくらですか
- 店員: 汚れの種類と範囲で金額が変わります。嘔吐・尿・灯油・タバコのどれに近いですか。座席1脚なら基本 18,000円から、嘔吐などの消臭セットは 23,000円からです。

見本3

- お客さん: 軽のタントでおもらしです。コンセントがありません
- 店員: タントの車内全体で、尿の消臭セットは 26,000円からが目安です。コンセントが無い場合は発電機の持込で +5,000円です。市区町村が分かれば対応エリアの目安をお伝えできます。番地は書かないでください。予約は下のボタンをタップしてください。

見本の欄が見つからない場合は、目的と手順だけ保存して先に進んでよい。

ページ右上または下の「保存」（Save）を押す。

## 5. 右の試し画面

画面の右側が試し画面（シミュレータ）です。無ければ上の「シミュレータ」を押す。

入力欄に「いくらですか」と打ち、送信する。

うまくいっている答えは、すぐ合計を言わず、嘔吐・尿・灯油・タバコのどれかを聞き、座席1脚は 18,000円から、消臭セットは 23,000円から、と返すものです。違う答えなら、保存を押し忘れていないか確認し、もう一度送る。

## 6. 英語のコードを出す

今の Conversational Agents の画面に、Manage や Integrations という文字はありません。次の順で開きます。

1. https://conversational-agents.cloud.google.com を開き、作ったエージェントの中に入る
2. 画面右上の歯車の右にあるアイコンにマウスを乗せる
3. **Publish** または **Publish agent** と出たアイコンを押す。出てくる **Conversational Messenger** が、サイトに出すチャットの窓です。Dialogflow Messenger という文字は、この画面にはありません
4. 左の縦アイコンにマウスを乗せ、**Integrations** と出たものを押しても同じです。中の **Conversational Messenger** で **Connect** を押す
5. 開いた窓の中を下まで見る
   - すでに有効なら、英語のコードが出ている
   - 出ていなければ、Environment は Draft、API は Unauthenticated API を選ぶ。ドメインの欄は空のままにする（`carinteriorcleaning.jp` は書かない）。**Enable the unauthenticated API** を押す。押したあとにコードが出る。ボタンが灰色で押せないときは、下の「請求をオンにする」を先に行う

上の Project 欄に出ている短い名前が `project-id` です。`agent-id` は窓のコードか、ブラウザのアドレスの `agents/` のうしろにあります。

## 7. コピーする3つ

窓の中の英語のコードから、引用符の中だけをメモ帳にコピーする。

```html
<df-messenger
  location="global"
  project-id="ここにプロジェクトの名前"
  agent-id="12345678-1234-1234-1234-123456789abc"
  language-code="ja">
```

- `project-id="..."` の引用符の中。短い英数字。画面いちばん上のプロジェクト名と同じことが多い
- `agent-id="..."` の引用符の中。ハイフンで区切られた長い番号
- `location="..."` の引用符の中。通常は `global`

この3つは秘密の鍵ではない。サービスアカウントの JSON や API キーはコピーしない。

## 8. 3つをチャットに貼る

Cloudflare の **Build variables and secrets**（ビルド変数とシークレット）は探しません。画面に無くて大丈夫です。Variables and Secrets にも入れません。

メモ帳の3つを、次の形でこのチャットに貼ってください。

```
location=global
project-id=ここにコピーした短い名前
agent-id=ここにコピーした長い番号
```

こちらでサイトのファイル `src/data/chatWidget.ts` に入れます。公開のサイト（`main`）に入った次の更新で、右下に丸いボタンが出ます。3つが空のあいだは、ボタンは出ません。

サービスアカウントの JSON や API キーは貼らないでください。

## 9. 手元の画面で話す

チャットの丸いボタンは、電話と LINE の帯の上に出ます。ボタンを押すと「車内清掃「特急便」」と「料金と汚れの相談」の窓が開きます。

メッセージを送って `Something went wrong, please try again.` と出るときは、サイトの不具合ではありません。Google が「ログインしていない人からの質問」を拒否しています。Google の返答は `Unauthenticated API is disabled`（誰でも話せる設定がオフ）です。**Conversational Messenger** の窓で、次を押します。

- Environment は Draft
- API は Unauthenticated API
- ドメインの欄は空のまま（手元の画面からも話せるようにするため）
- **Enable the unauthenticated API** を押す

押したあと、ページを再読み込みして「いくらですか」と送ります。予約の案内では、文章の下に「電話する」と「LINEで見積もり」のボタンが出ます。番号やURLの文字をなぞる必要はありません。ボタンをタップすると、電話またはLINEが開きます。

## 10. 請求をオンにする

**Enable the unauthenticated API** が灰色のときは、プロジェクト `chatbotcarinteriocleaning` に支払い口座が付いていません。チャットの画面ではなく、Google Cloud の請求の画面で付けます。

1. チャットを作ったときと同じ Google アカウントで、次を開く。https://console.cloud.google.com/billing/projects
2. 上の方の **My projects**（マイプロジェクト）を押す
3. 一覧から `chatbotcarinteriocleaning` を探す。Billing account の列が **Billing is disabled** なら、まだオフです
4. その行の右端の縦三点（⋮）を押し、**Change billing** を押す
5. すでに支払い口座があれば、それを選んで **Set account** を押す。一覧が空なら **Create account** を押し、名前、国（日本）、クレジットカードを入れて作ってから、もう一度 4 と 5 を行う
6. チャットの画面に戻り、ページを再読み込みして **Enable the unauthenticated API** を押す

オンにしても、その場で大きな金額は引き落とされません。使った分が、後からそのカードに請求されます。縦三点に **Change billing** が無いときは、その Google アカウントに請求を変える権限がありません。
